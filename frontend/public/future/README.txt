FUTURE BOT BUILDER — Assets de imagem esperados
================================================

Solte os arquivos abaixo nesta pasta. Enquanto não existirem, os gradientes
neon do tema seguram o visual. Cada arquivo dá upgrade automático ao ser
disponibilizado (nenhuma alteração de código necessária).

bg.jpg
  Tamanho recomendado: 2560 x 1440 px
  Conteúdo: nebulosa escura (tonalidades navy/roxo) com grade sutil
  Formato: JPEG, compressão media (~300KB)
  Uso: plano de fundo do overlay inteiro

icon-atendimento.png
  Tamanho: ~512 x 512 px, fundo transparente
  Conteúdo: ícone sci-fi de fone/atendimento (tom azul elétrico)
  Uso: decoração sutil no mode-card "Atendimento" (opacity 25%)

icon-recovery.png
  Tamanho: ~512 x 512 px, fundo transparente
  Conteúdo: ícone sci-fi de moeda/recuperação (tom âmbar/dourado)
  Uso: decoração sutil no mode-card "Recovery" (opacity 25%)

icon-prospeccao.png
  Tamanho: ~512 x 512 px, fundo transparente
  Conteúdo: ícone sci-fi de alvo/prospecção (tom roxo/magenta)
  Uso: decoração sutil no mode-card "Prospecção" (opacity 25%)

hud-hbx.png
  Tamanho: ~400 x 400 px, fundo transparente
  Conteúdo: logotipo HBX estilizado (versão neon/wireframe)
  Uso: centro do HUD hexagonal no topo do overlay

grid.png  [OPCIONAL]
  Tamanho: 512 x 512 px, seamless (tileable)
  Conteúdo: grade de pontos ou linhas finas em cinza muito escuro
  Uso: textura opcional de fundo (se quiser adicionar como bg extra)
