# Áudio local

Esta pasta recebe locuções opcionais e não deve guardar material com direitos de uso indefinidos.

Nomes reconhecidos:

```text
commercial.wav | commercial.mp3 | commercial.m4a
tutorial-admin.wav | tutorial-admin.mp3 | tutorial-admin.m4a
tutorial-entregador.wav | tutorial-entregador.mp3 | tutorial-entregador.m4a
```

A locução precisa começar no tempo zero e acompanhar a ordem de `content.mjs`. Use o `.srt` gerado como guia de tempo. Prefira voz clara, sem leitura acelerada e sem trilha popular protegida por direitos autorais.

Os arquivos de áudio são ignorados pelo Git.
