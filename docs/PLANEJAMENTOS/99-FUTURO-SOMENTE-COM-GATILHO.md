# 99 — FUTURO, SOMENTE QUANDO O GATILHO EXISTIR

Estes itens realmente não foram construídos, mas não entram na fila atual. Criar plano próprio apenas quando o gatilho comercial ou técnico ocorrer.

| Ideia | Gatilho para planejar |
|---|---|
| Cobrança recorrente do cliente final | Um cliente piloto aceitar migrar pelo menos 20 cobranças recorrentes |
| Painel do contador multiempresa | Um contador real aceitar piloto com pelo menos 5 empresas |
| SDR de IA semiautomático | Piloto manual por 60 dias, resposta acima de 8%, opt-out abaixo de 2% e zero dano de chip |
| Whisper para áudio | VPS suportar o worker sem degradar Radar/WhatsApp e existir demanda medida |
| Export “seus dados são seus” | Objeção comercial recorrente ou primeiro cliente pedir portabilidade |
| Fábrica automática de sites | Mais de um site novo por mês |
| Canal oficial WhatsApp como produto | Cliente piloto aceitar custo por conversa e templates |
| SEO programático/API de dados | Paywall backend, rate limit e funil de conversão maduros |

## Regra

Sem gatilho, não implementar. Quando houver gatilho, criar um novo arquivo pequeno nesta pasta, executar uma microetapa por conversa e remover a linha daqui.
