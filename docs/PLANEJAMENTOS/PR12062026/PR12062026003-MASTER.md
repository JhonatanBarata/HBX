## O que entrou

### Rota e guard
- `frontend/src/app/(app)/master/` — rota canônica `/master`.
  - `page.client.tsx`: layout com sidebar própria de janelas (mesmas classes
    `side`/`nav-item`/`topbar` do kit), guard `useCurrentUser().isSystemMaster`
    (não-master vê "Acesso restrito" + botão Dashboard), lista de empresas
    compartilhada entre janelas (`GET /modules/master/companies`).
- `/dashboard/master` (alias) agora redireciona para `/master` — o backend
  devolve `next=/dashboard/master` no login do master (auth.service:1197),
  então o login do master cai em `/master` SEM mexer no backend.
- `shell.tsx`: item **Master** no menu do avatar só para `isSystemMaster`
  (tipo `CurrentUser` ganhou `role`/`isSystemMaster`); aviso do Dashboard para
  master agora tem botão "Ir para o /master".
- `lib/api.ts`: `apiFetch` não força mais `Content-Type: application/json`
  quando o body é `FormData` (uploads da janela E-mails).
