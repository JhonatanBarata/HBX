# PRIORIDADE — 2026-04-04 — Login cinematográfico com motion real

## Pedido

Criar uma nova direção visual para a tela de login do HBX com foco em tecnologia, emoção, luz, profundidade e sensação de energia viva.

## Ideia central

Antes do login:

- ambiente mais escuro
- luzes mais apagadas
- pulsos aleatórios leves
- DNAs / energias / partículas respirando ao fundo
- sensação de sistema vivo, mas ainda contido

Ao autenticar:

- tudo acende forte por cerca de 2 segundos
- explosão luminosa mais intensa
- energia convergindo para o logo HBX
- depois tudo sendo sugado para dentro do HBX
- devolvendo a tela / transicionando para o sistema

## Objetivo visual

- muito mais cinematográfico
- muito mais tecnológico
- muito mais emotivo
- sensação de interface viva
- 3D, luzes e profundidade sem economizar
