# HBX — restantes reais

## 1. Central WhatsApp
- Implementar o vínculo rápido real por QR, separado da integração oficial Meta.
- Manter os estados e a persistência atuais da Central WhatsApp, mas trocar o modo temporário de "estrutura de produto" para conexão técnica funcional.

## 2. Produtividade global do front
- Levar a command palette para escopo global do HBX, não só no módulo Vendas.
- Padronizar ações contextuais rápidas entre Vendas, Atendimento e Recovery com a mesma base visual.

## 3. Núcleo unificado entre módulos
- Fechar o perfil realmente unificado entre Vendas, Atendimento e Recovery para que o mesmo contato/empresa atravesse os três contextos com menos pontos paralelos.
- Preservar os módulos separados por objetivo da interação, mas fortalecer a leitura compartilhada do histórico geral.
