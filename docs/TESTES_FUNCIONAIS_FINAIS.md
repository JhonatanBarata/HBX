# Testes funcionais finais

Checklist simples para validar o HBX no localhost e ir corrigindo com o Copilot.

## Cadastro / login
- criar conta nova com e-mail novo
- confirmar e-mail
- testar login antes da confirmação
- testar login depois da confirmação
- testar cadastro PF
- testar cadastro PJ
- testar aviso para PJ com e-mail público
- testar campo de origem / indicação

## Trial / onboarding
- validar se o trial inicia após confirmação
- validar dias restantes
- validar módulo inicial escolhido
- validar primeiro acesso premium

## Vendas
- criar lead manual
- puxar lead do webscraping
- editar card
- agendar retorno
- encerrar card
- testar drag and drop
- validar timeline
- validar memória comercial
- validar deduplicação por telefone

## Webscraping
- fazer busca nova
- fazer busca repetida
- validar limite diário no trial
- validar badge/cache técnico global
- validar envio para Vendas

## Financeiro
- abrir módulo Financeiro
- validar plano atual
- validar trial/status discreto
- validar desconto global anual
- validar desconto manual
- validar meses grátis
- gerar PIX
- validar QR Code e copia e cola
- validar checkout cartão
- validar atualização automática após pagamento

## Master
- validar leitura geral das empresas
- validar trial e dias restantes
- validar uso de webscraping
- validar cache global
- validar financeiro por empresa
- validar descontos
- validar Central WhatsApp
- validar filtros do Master

## Central WhatsApp
- abrir central
- testar modo rápido por QR
- testar atualização de status
- testar desconexão
- validar modo oficial Meta
- validar aceite de contato técnico
- validar leitura no Master

## Atendimento / Recovery
- validar se continuam funcionando
- validar se não quebraram após unificação com Vendas
- validar leitura compartilhada do perfil

## Ajustes finais
- anotar o que estiver feio
- anotar o que estiver confuso
- anotar o que estiver quebrado
- corrigir com o Copilot em blocos curtos
