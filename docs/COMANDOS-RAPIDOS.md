# Comandos rapidos

Atalhos simples para rodar operacoes locais no HBX sem decorar comandos longos.

| Comando | Para que serve |
| --- | --- |
| `npm run up` | Sobe tudo local. |
| `npm run down` | Derruba tudo local. |
| `npm run backend:restart` | Reinicia so o backend. |
| `npm run backend:logs` | Mostra os logs do backend acompanhando em tempo real. |
| `npm run backend:rebuild` | Use quando mexeu em dependencia ou no Dockerfile do backend. |
| `npm run db:restart` | Reinicia so o banco. |
| `npm run prisma:generate` | Use quando mexeu no `schema.prisma`. |
| `npm run prisma:migrate` | Aplica migrations no banco. |
| `npm run front:dev` | Sobe so o frontend. |
| `npm run publish:dry` | Simula publicacao. |
| `npm run new` | Publica de verdade. |
