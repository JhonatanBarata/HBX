The base HBX surface — a liquid-glass panel for grouping content in the workspace.

```jsx
<Card eyebrow="Recovery" title="Dinheiro parado" action={<IconButton label="Abrir">→</IconButton>}>
  <p>Régua de cobrança e reativação via WhatsApp.</p>
</Card>
```

`tone` adds a corner spotlight (`brand`/`accent`/`warning`). Omit the header props for a bare panel. For a single KPI use `StatCard`.
