Rounded-square avatar (initials on a brand gradient, or an image) for users, leads and companies.

```jsx
<Avatar name="Marina Alves" />
<Avatar name="HBX Suporte" tone="success" size={32} />
<Avatar src="/uploads/lead.jpg" name="Auto Center Sul" />
```

Note: HBX avatars use rounded squares (radius-sm), not circles. `tone` picks the gradient; `size` is in px.
