Pill badge for status, counts and taxonomy in HBX UI.

```jsx
<Badge tone="success">Recuperado</Badge>
<Badge tone="brand">87% prioridade</Badge>
<Badge tone="danger">Atrasado</Badge>
```

Tones: `neutral` (default), `brand`, `success`, `warning`, `danger`. Always a 999px pill, 800-weight, ~11px. For free-text filter chips that the user toggles, use `Chip` instead.
